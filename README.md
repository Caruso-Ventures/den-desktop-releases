# The Den — Desktop Releases

Public release and auto-update feed for the Den desktop app (macOS).

Install: download the latest `.dmg` from [Releases](https://github.com/Caruso-Ventures/den-desktop-releases/releases/latest), drag **The Den** to Applications, sign in with your @carusoventures.com Google account.

The app updates itself automatically. Source lives in the private cv-den monorepo (apps/desktop).
